# HR Employee Attrition & Retention Analytics

## Project Overview
This is an end-to-end HR analytics project developed using Microsoft Power BI. The project analyzes employee attrition, workforce demographics and retention trends to support data-driven HR decision-making.

## Business Problem
Employee attrition can affect organizational productivity and workforce stability. This project aims to understand employee turnover patterns and identify departments, age groups and job roles with higher attrition.

## Project Objectives
- Analyze overall employee attrition.
- Understand workforce demographics.
- Identify attrition patterns across departments.
- Analyze employee attrition by age group and job role.
- Provide insights to support employee retention strategies.

## Tools & Technologies
